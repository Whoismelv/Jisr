# 🌉 جسر

**شغّل ألعاب ويندوز (ستيم) على ماك آبل سيليكون — بضغطات معدودة، وبلا Terminal.**

تطبيق مفتوح المصدر وبسيط يخلي ألعاب **Steam** للويندوز تشتغل على أجهزة **Mac M1/M2/M3/M4** — بواجهة عربية أصلاً (ومتوفرة بالإنجليزية).

> 🧪 **الوضع الحالي:** نسخة تجريبية مبكرة — أول اختبار ميداني على الماك. حاسب إن الأشياء تتطوّر بسرعة.

## كيف يشتغل؟

يستعمل التطبيق **[Wine](https://www.winehq.org)** (طبقة ويندوز مفتوحة المصدر) + **Rosetta 2** (ترجمة آبل) داخل بيئة معزولة تماماً (قارورة) — **التطبيق نفسه ما يطلب صلاحيات مدير**، وكل شي داخل مكتبته. *(GStreamer متطلب منفصل من Wine ويحتاج كلمة سر الماك — مرة وحدة.)*

## ⚡ طبقة الأداء

- **DXVK-macOS async** تلقائياً بعد تجهيز Wine — يحوّل DirectX 10/11 إلى Vulkan ثم MoltenVK ثم Metal. تنزيله **2.8MB فقط**، وإذا فشل ترجع الألعاب تلقائياً لـWineD3D بلا توقف.
- **msync** مفعّل (`WINEMSYNC=1`) لتقليل تأخير المزامنة على Apple Silicon.
- **مكتبة ستيم تلقائية:** جسر يقرأ ألعاب ستيم المثبّتة داخل القارورة ويعرضها في المكتبة — اضغط تشغيل وستيم يفتحها مباشرة.
- **اختيار طبقة الرسومات:** تلقائي / DXVK / WineD3D من الإعدادات — أعد تشغيل ستيم بعد التغيير حتى تصل الطبقة لألعابه.

📊 **مقارنة صادقة مع Whisky وCrossOver** (وين نتفوق ووين لسه متأخرين): [docs/COMPARISON.md](docs/COMPARISON.md)

## 🧰 قبل ما تبدأ (متطلبات — مرة وحدة)

1. **Rosetta 2:** أول تشغيل، الماك يطلبه تلقائياً (اضغط تثبيت) — أو يدوياً: `softwareupdate --install-rosetta --agree-to-license`
2. **GStreamer.framework** (متطلب محرّك Wine رسمياً — لجميع المستخدمين، يحتاج كلمة سر الماك):
   👉 [gstreamer-1.0-1.28.5-universal.pkg](https://gstreamer.freedesktop.org/data/pkg/osx/1.28.5/gstreamer-1.0-1.28.5-universal.pkg) (~146 MB)

## 📥 التنزيل
من صفحة **[الإصدارات](../../releases)** — نزّل ملف `.dmg`.

**أول تشغيل (مهم):** النسخ الحالية غير موقّعة بشهادة آبل (شهادة مدفوعة سنوياً — تأتي لاحقاً)، والأنظمة الحديثة تعرض أحياناً رسالة «التطبيق تالف» — وهو **سليم تماماً**، مجرد «حجر صحي» (Quarantine) على البرامج غير الموقّعة. الحل أمر واحد في Terminal ثم يشتغل عادي للأبد:

```bash
xattr -cr /Applications/jisr.app
```

*(لو نقلت التطبيق لمكان آخر: اكتب `xattr -cr ` وضع مسافة، ثم اسحب أيقونة التطبيق إلى نافذة Terminal — يكتب المسار لحاله. و«كليك يمين ← فتح» قد يعمل أيضاً لكن الأمر فوق أضمن.)*

## 🛡️ المبادئ

- **أمان أولاً:** كل تنزيل بتحقّق SHA-256، قائمة نطاقات مسموحة صارمة، بلا تنفيذ أوامر نظام، بلا تتبّع (صفر Telemetry)
- **إفصاح مسؤول:** لأي ثغرة — راجع [SECURITY.md](SECURITY.md) (بخصوصية، بلا Issue عام)
- **معزول:** كل شي داخل مكتبة التطبيق — احذفهن ويروح كل شي معهن
- **لا نوزّع أي ملف مملوك:** المحركات وستيم تُنزَّل رسمياً من مصادرها وقت التشغيل
